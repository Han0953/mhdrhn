# Technology logos used by mhdrhn.

Original source files are stored unchanged. `manifest.json` records the source URL, pinned collection revision where available, retrieval date, byte count, and SHA-256 of every asset. CSS alpha masks show vector artwork using the site's ink color. Cirkit's original PNG uses CSS grayscale/contrast and multiply/screen compositing so its white background does not turn into an opaque square. Source files are not rewritten or traced.

Collections are independent projects, not official representatives of all brands:

- Simple Icons: CC0-1.0 collection, https://github.com/simple-icons/simple-icons . Brand-specific source/licence conditions still apply. PHP's logo is CC-BY-SA-4.0 (PHP project, https://php.net/download-logos.php); Git's logo is CC-BY-3.0 (Jason Long, https://git-scm.com/community/logos). Artwork geometry is unchanged; monochrome presentation is applied through CSS.
- Devicon: MIT, Copyright (c) 2015 konpa. Full licence in `DEVICON-LICENSE.txt`.
- Lobe Icons: MIT, Copyright (c) 2023 LobeHub. Full licence in `LOBE-ICONS-LICENSE.txt`.
- Google Antigravity: official one-color press asset, https://antigravity.google/press .
- Wokwi: official favicon SVG, https://wokwi.com/ .
- Blynk: official monochrome logotype linked by its website stylesheet, https://www.blynk.io/ .
- Cirkit Designer: official transparent 32 px favicon PNG, https://www.cirkitdesigner.com/ .

All brand names, marks, and product identities remain property of their respective owners. Use identifies technologies named in this portfolio and does not imply endorsement, partnership, certification, or proficiency.

Generic symbols are deliberately retained where a suitable distinct asset is unverified or published use/recoloring restrictions were found. In particular: Visual Studio Code (https://code.visualstudio.com/brand), Raspberry Pi (https://www.raspberrypi.com/trademark-rules/), and Microsoft Office (https://www.microsoft.com/en-us/legal/intellectualproperty/trademarks). Their names remain visible; no invented brand logo is substituted.

Maintenance: `node scripts/vendor-technology-logos.mjs --download` fetches only the reviewed plan and refuses to overwrite an asset with differing bytes. It is not run by build or at runtime. Review brand rules again before expanding the asset set. Collection licence availability is not a blanket trademark licence.
